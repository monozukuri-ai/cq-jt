# Documentation

cq-jt reads selected JT display-data profiles through a Rust core and Python bindings.

- [API guide](model-api.md): inspect, decode, read, access arrays and export GLB
- [Compatibility and limitations](compatibility.md): versions, supported data and experimental behavior
- [Conversion example](https://github.com/monozukuri-ai/cq-jt/blob/main/examples/README.md): a standalone command-line script
- [Rust core](https://github.com/monozukuri-ai/cq-jt/blob/main/crates/jt-core/README.md): use the reader without Python
- [License and third-party notices](https://github.com/monozukuri-ai/cq-jt/blob/main/THIRD_PARTY_NOTICES.md)

Start with the [quick start](https://github.com/monozukuri-ai/cq-jt/blob/main/README.md#quick-start). Use `python -m cq_jt <command> --help` for the complete CLI option list.
